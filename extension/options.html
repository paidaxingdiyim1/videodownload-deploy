网页视频下载器 · 设置

扩展负责识别网页里的视频流，真正的下载和解密由下载服务完成。请先在服务所在电脑上运行 start.bat（本机）或 start-lan.bat（局域网服务器）。

保存位置

视频旁的下载按钮和资源面板按这里的选择保存；选「每次询问」时，点下载会弹出「服务器 / 本机」小菜单。扩展弹窗顶部也能随时切换。

服务器（远程）

局域网服务器地址，如 http://yourserver:8765 或 http://192.168.x.x:8765。端口变动请同步修改。

Token 会打印在服务器上 start-lan.bat 的窗口里，可从那里复制。

本机服务

保存到本机时使用，一般保持默认即可。

Token 也会打印在本机 start.bat 的窗口里，可从那里复制。

下载行为

关闭后仍可通过扩展图标里的资源列表下载。

小于该宽度的视频（多为广告/装饰图）不显示按钮。

链路测速

先测服务器上每个代理节点的延迟，再逐个真下数据量出 MB/s；选中哪条，后续下载就走哪条。测的是服务所在电脑的 Clash 节点，跟浏览器自身的代理无关。

页面里还能批量提交链接（一行一个）。地址和 Token 直接用上面填好的，会自动带上。

标题整理（AI 一键整理）

点一下，服务器会用 AI 对下载目录里尚未整理的视频做结构化命名：识别剧集、聚合系列、繁转简、提取番号，自动放进「番剧 / 电视剧」目录并生成 .nfo 元数据（Jellyfin 按「节目」类型加库即可分季分集）。AI 配置从服务器的 cc-switch 里读取，不落盘、不入库。整理结果会明确返回「已完成 / 失败原因」。
